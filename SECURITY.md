# Segurança

Reporte vulnerabilidades em privado aos administradores da organização Ávila Ops.
Não abra issue pública contendo credenciais, dados de clientes ou detalhes exploráveis.

Os pacotes não devem conter tokens, arquivos `.env`, certificados ou chaves privadas.
Credenciais são configuradas no host autorizado. A instalação de um plugin não concede
acesso automático aos MCPs ou sistemas internos.
