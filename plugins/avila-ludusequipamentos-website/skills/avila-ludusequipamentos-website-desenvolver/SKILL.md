# Site Ludus Equipamentos

1. Leia [o contexto da aplicacao](references/aplicacao.md). Localize o checkout; se nao estiver acessivel, solicite sua localizacao.
2. Leia AGENTS.md na raiz e nos diretorios afetados, README e os manifestos reais. Confira git status e preserve alteracoes existentes.
3. Localize os simbolos envolvidos, consumidores, configuracoes e testes. Derive os comandos dos arquivos do projeto; nao suponha framework ou gerenciador.
4. Implemente apenas o escopo pedido seguindo as convencoes locais. Verifique identidade e empresa/tenant antes de qualquer operacao com dados.
5. Execute as verificacoes pertinentes e examine o diff. Para mudancas visuais, verifique os fluxos afetados no navegador quando disponivel.
6. Informe arquivos alterados, resultado das verificacoes e limitacoes. Diferencie implementacao local, publicacao e validacao em producao.

## Acesso a ferramentas

Este pacote fornece um fluxo de desenvolvimento com acesso ao checkout. Nao declara ferramentas de negocio nem conexao MCP. Descubra as ferramentas realmente disponiveis antes de usa-las. Nunca invente nomes, endpoints, identificadores de apps ou provas de acesso. Nunca copie segredos para o pacote.
