# Suporte

Abra uma issue neste repositório com o plugin, versão, host, entrada utilizada, resultado
observado e logs sanitizados. Use o canal privado da organização quando o relato depender de
dados não públicos. Remova tokens, dados pessoais e dados de clientes.

Falhas de autenticação ou autorização devem informar somente o status e o recurso afetado.
